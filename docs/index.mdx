Folio is a file-based documentation engine for Markdown and MDX content. It
combines Vite, Tailwind CSS v4, server-rendered pages, syntax highlighting, and
a customizable navigation theme. The content can document any project,
library, API, or product.

<Callout type="tip">
  This documentation site is built with Folio itself.
</Callout>

## What you get

- File-based MDX routes from the `docs/` directory.
- Automatic sidebar categories and page navigation.
- Static production builds with server-rendered content.
- Customizable themes, layouts, components, and design tokens.
- A local, copy-paste-owned default theme that can be customized in every generated project.
