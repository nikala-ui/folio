---
title: i18n plugin foundation
description: Normalize supported locale metadata without changing documentation routes.
order: 3
---

Folio's i18n foundation plugin validates and normalizes a page's locale
metadata. It reads a locale from frontmatter and applies the configured
default when a page does not declare one.

```ts
import { createI18nPlugin } from "./src/plugins/i18n/index.js";

export default {
  plugins: [
    createI18nPlugin({
      defaultLocale: "en",
      locales: ["en", "ka"],
    }),
  ],
};
```

Declare an explicit locale when a page differs from the default:

```md
---
title: საწყისი გვერდი
locale: ka
---
```

For real localized routes, store content in locale directories:

```text
docs/
├── guide.mdx        # default locale, served at /guide
└── ka/
    └── guide.mdx    # served at /ka/guide
```

An explicitly prefixed default locale is also normalized:

```text
docs/en/guide.mdx    # served at /guide
```

Every generated route points to its actual MDX `filePath`, so the plugin does
not duplicate untranslated source content.

The plugin preserves `slug` and `url`, and writes the normalized locale back
to the configured frontmatter key. An unsupported locale fails the page
transformation with plugin metadata, so invalid translations cannot silently
enter the build.

The foundation does not render a language switcher yet. That requires a
separately specified navigation contract.
