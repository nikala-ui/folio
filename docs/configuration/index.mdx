Folio loads a TypeScript configuration file from the project root.
The preferred filename is `docs.config.ts`:

```ts
import type { DocsConfig } from "@nikala-ui/folio";

const config: DocsConfig = {
  title: "Project Documentation",
  description: "Documentation for my project.",
  contentDir: "docs",
  favicon: "/favicon.ico",
};

export default config;
```

The loader also accepts JavaScript and legacy `nikala.config.*` filenames.
Configuration values are merged with the engine defaults. Nested `theme`,
`navigation.sidebar`, `shiki`, and `search` values are merged as well.

branding in engine source.
